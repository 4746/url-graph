# URL Graph

**URL Graph** — плагін для Obsidian, який показує зв’язки між Markdown-нотатками за URL, указаними в їхніх властивостях. Якщо одна нотатка посилається на адресу іншої, між ними з’являється зв’язок на інтерактивному графі.

Плагін допомагає переглядати структуру збережених вебсторінок, знаходити сторінки з багатьма вхідними посиланнями та досліджувати зв’язки окремої нотатки. Він працює в окремій вкладці, незалежно від стандартного графа Obsidian.

## Можливості

- Загальний граф URL-зв’язків і локальний граф окремої нотатки.
- Вхідні та вихідні зв’язки у правій бічній панелі.
- Фільтри за папками, доменами й властивостями нотаток, наприклад `language` або `status`.
- Розмір вузлів за кількістю вхідних або вихідних зв’язків і групування за розміром.
- Підсвічування сусідів і вихідних зв’язків при наведенні.
- Підказки з назвою нотатки та кількістю її зв’язків.
- Налаштування підписів, кольорів, відстані між вузлами та вигляду ліній.
- Автоматичне оновлення після змін нотаток.
- Український та англійський інтерфейс.

## Встановлення

Потрібен **Obsidian 1.8.7 або новіший**.

Для ручного встановлення:

1. Візьміть файли готової збірки: `main.js`, `manifest.json` і `styles.css`.
2. Створіть у своєму сховищі папку `.obsidian/plugins/url-graph/` і помістіть туди ці три файли.
3. Перезавантажте Obsidian.
4. Увімкніть **URL Graph** у **Налаштування → Сторонні плагіни** (**Settings → Community plugins**).

## Перший граф

Кожна нотатка, яку ви хочете бачити на графі, повинна мати властивість `url` з абсолютною HTTP або HTTPS адресою.

Наприклад, створіть нотатку `Home.md`:

```markdown
---
url: "https://example.com/"
language: "en"
---

See [Pricing](https://example.com/pricing).
```

І нотатку `Pricing.md`:

```markdown
---
url: "https://example.com/pricing"
language: "en"
---

Pricing information.
```

Виберіть іконку **URL Graph** на лівій бічній панелі або команду **URL Graph: Відкрити граф** у палітрі команд. На графі з’являться два вузли зі зв’язком **Home → Pricing**.

Якщо ваші URL зберігаються в іншому полі, укажіть його назву в **Налаштування → URL Graph → Властивість URL**. Типова назва — `url`.

## Робота з графом

| Дія | Як виконати |
| --- | --- |
| Змінити масштаб | Прокрутіть коліщатко миші або використайте жест масштабування |
| Перемістити граф | Перетягніть порожню область |
| Перемістити вузол | Перетягніть його |
| Відкрити нотатку | Натисніть на вузол |
| Побачити сусідів і вихідні зв’язки | Наведіть курсор на вузол |
| Переглянути назву та кількість зв’язків | Наведіть курсор на вузол з увімкненими підказками |
| Відкрити меню вузла | Натисніть правою кнопкою миші |

Між кожною парою вузлів відображається одна лінія. Стрілка на одному кінці означає односторонній зв’язок; стрілки на обох кінцях — взаємні посилання. Стрілки можна приховати в налаштуваннях графа.

На панелі графа є іконки **Показати весь граф**, **Розташувати вузли**, **Перебудувати індекс**, **Показати зв’язки** та **Налаштування графа**. Наведіть курсор на іконку, щоб побачити її підказку.

Зміни нотаток підхоплюються автоматично. Якщо потрібно повторно перевірити все сховище, виберіть **Перебудувати індекс**. Під час обробки відображається індикатор завантаження.

### Локальний граф

Натисніть правою кнопкою на вузол і виберіть **Відкрити локальний граф**. В окремій вкладці відкриється вибрана нотатка, її безпосередні вхідні та вихідні сусіди й зв’язки з ними.

Це зручно, коли загальний граф великий і частина зв’язків не вміщується на екрані. Активні фільтри застосовуються й до локального графа.

### Панель зв’язків

У меню вузла виберіть **Показати зв’язки**, щоб відкрити праву панель. Для поточної нотатки її також можна відкрити командою **URL Graph: Відкрити URL-зв’язки**.

На панелі є два розділи: **Вихідні** та **Вхідні**. Їх можна згортати й розгортати. Натискання на запис відкриває нотатку; іконка прицілу показує її на графі. Іконка рамки біля поточної нотатки вміщує її видимих сусідів у вікно графа.

Панель показує всі URL-зв’язки вибраної нотатки. Приховані фільтрами нотатки позначаються у списку, і їх можна відкрити для читання.

При відкритті іншої Markdown-нотатки список оновлюється. Перехід до іншого типу перегляду очищує попередній вибір. Кнопка **×** біля заголовка закриває вкладку та прибирає закріплене підсвічування. Стандартні панелі вхідних і вихідних посилань Obsidian залишаються доступними.

## Налаштування відображення

Виберіть іконку повзунків на панелі графа, щоб відкрити **Налаштування графа**.

| Параметр | Що змінює |
| --- | --- |
| Показувати стрілки | Показує або приховує стрілки на кінцях ліній |
| Показувати підказку вузла | Показує назву та кількість вхідних / вихідних зв’язків при наведенні |
| Показувати ізольовані нотатки | Показує нотатки без зв’язків у поточному графі |
| Підписи вузлів | Завжди видимі, при наведенні або виборі, приховані |
| Назва вузла | Назва файлу, шлях у сховищі або URL |
| Розмір вузлів | Однаковий, за кількістю вихідних або вхідних зв’язків |
| Групувати вузли за розміром | У режимах розміру за кількістю зв’язків розташовує більші вузли ближче до центру, менші — до країв |
| Відстань між вузлами | Змінює щільність розташування |
| Товщина та непрозорість ребер | Змінює вигляд ліній |
| Кольори вузлів | Колір теми, власний колір, групування за доменом або папкою |

Розміри вузлів і числа в підказках враховують зв’язки поточного видимого графа. Діаметри масштабуються від 22 до 88 відносно найменшої та найбільшої кількості зв’язків серед видимих вузлів. Якщо кількість у всіх однакова, їхні розміри однакові. Після фільтрації значення та шкала можуть змінитися. Зустрічні посилання враховуються окремо, навіть якщо показані однією лінією.

## Фільтри

### За властивостями нотаток

У **Налаштування → URL Graph → Властивості для фільтрації** введіть назви полів через кому:

```text
language, category, status
```

Для кожного поля на панелі графа з’явиться список доступних значень. Наприклад, якщо нотатки містять `language: "de"`, виберіть `de`, щоб побачити лише їхні вузли та зв’язки між ними. Виберіть **Усі значення**, щоб прибрати обмеження для цього поля.

Кілька фільтрів діють одночасно: `language = de` і `status = published` залишать лише нотатки, що відповідають обом умовам. Підтримуються прості значення та списки, наприклад `category: [seo, pricing]`. Назви полів і значення чутливі до регістру.

### За папками та доменами

У **Налаштування → URL Graph → Фільтри графа** задайте папки або домени для включення чи виключення. Указуйте один запис на рядок, потім виберіть **Застосувати фільтри**.

- Папка `blog` охоплює також її підпапки. Шлях указується від кореня сховища; `/` означає нотатки в корені.
- Домен `example.com` охоплює також його піддомени. Указуйте домен без шляху сторінки; маски `*` не підтримуються.
- Порожній список включення не обмежує граф. Виключення мають пріоритет.

## Мова інтерфейсу

Типово плагін використовує мову Obsidian. У **Налаштування → URL Graph → Мова** можна незалежно вибрати **English**, **Українська** або **Використовувати мову Obsidian**. Для непідтримуваних мов використовується англійська. Мова плагіна змінюється без перезапуску.

## Як визначаються зв’язки

- На граф потрапляють лише нотатки з коректним HTTP або HTTPS URL у вибраній властивості.
- Зв’язок створюється, коли посилання в тексті однієї такої нотатки збігається з URL іншої. Зовнішні адреси без відповідної нотатки ігноруються.
- Фрагменти `#section` і завершальний `/` не заважають зіставленню. Протокол, регістр шляху та параметри запиту враховуються; перенаправлення не перевіряються.
- Повторні посилання на ту саму нотатку не дублюють зв’язок. Посилання нотатки на саму себе ігноруються.
- Якщо кілька нотаток мають однаковий URL, посилання веде до кожної з них.
- Посилання в коді, зображеннях і коментарях не створюють зв’язків. Внутрішні `[[wiki-посилання]]` також не враховуються цим графом.

Якщо очікуваного вузла немає, перевірте властивість URL і активні фільтри. Якщо немає зв’язку, перевірте URL обох нотаток і посилання в тексті вихідної нотатки.

## Приватність

URL Graph працює локально, не завантажує вказані вебсторінки, не надсилає мережевих запитів і не збирає телеметрію. Плагін лише читає Markdown-файли та ніколи не змінює їхній вміст або властивості. Зберігаються лише налаштування самого плагіна.
